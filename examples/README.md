# Example outputs

These files show the exact text format the extension produces. They were generated by the extension's own formatting code (`src/result.js`) from **invented sample data** – the channel, video titles and transcript text are not real.

| File | Results page settings |
|---|---|
| `output-combined-paragraphs.txt` | Readable paragraphs · One TXT with every video |
| `output-combined-timestamps-no-sound-tags.txt` | Lines with timestamps · One TXT with every video · Remove sound tags |
| `output-single-video-lines.txt` | One line per caption · One TXT per video (one of the files) |

Each combined file ends with a "Videos without a transcript" section, so the user can see which videos failed and why.
